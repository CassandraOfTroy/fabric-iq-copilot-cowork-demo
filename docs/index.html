Set it up

  • Fabric capacity F2 or higher (or P1 or higher), and the data agent tenant settings. Outside the US and EU, cross-geo processing for AI.
  • Each user: a Microsoft Copilot licence (or an Office 365 commercial subscription), and read access to the data agent and its sources.
  • Publish with a detailed description, then tick Publish to Agent Store. Users chat with it or @mention it.
  • Optional: add an ontology Preview as a context layer. It adds business meaning, and the query still runs on the bound source, as the user. See .
  • Want several data agents in one specialist? Add them to a Copilot Studio agent with the Fabric IQ Data MCP tool, then publish to Teams and Microsoft 365 Copilot.

Ontology in Microsoft 365: it travels as context, through an agent

An ontology Preview is the business-context layer of Fabric IQ: entity types, relationships, definitions, rules, and bindings to data in Fabric. It “isn't itself a general-purpose data-query engine.” So you don't export it to Microsoft 365. An agent uses it as context and queries the bound data as the user, and people open that agent in Microsoft 365.

What it means here

  • The Caldova demo has no ontology. The Power BI semantic model owns the metrics, and all three options use it as it is.
  • Need shared business context across several models or operational data? Add an ontology to a data agent as context.
  • Need it in Microsoft 365 without building in Fabric? A Copilot Studio agent with the Fabric IQ MCP tool, published to Microsoft 365 Copilot.
  • Either way, the ontology adds meaning. The numbers still come from the bound source, with the user's permissions.

Which option? Three questions

Start with the data, then the job. Teams often use more than one option.

    Combine them

    • Copilot Chat for a quick, general analysis of Power BI insights, explained with your work insights.
    • Cowork when Copilot should also do the follow-up work: emails, documents and decks, meetings, recurring summaries.
    • A data agent for Fabric data across several semantic models, lakehouses, warehouses or KQL databases, optionally with ontology context.
    • A declarative agent for one business process that relies on Power BI insights and work insights.
    • A specialist that also needs data agents: a Copilot Studio agent with the Fabric IQ Data MCP tool. “You can add more than one Fabric data agent to the same Copilot Studio agent, along with other tools and knowledge sources.”
