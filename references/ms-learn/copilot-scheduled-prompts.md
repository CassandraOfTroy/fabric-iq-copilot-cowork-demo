# Manage scheduled prompts for Microsoft Copilot

Source: https://learn.microsoft.com/microsoft-365/copilot/scheduled-prompts (fetched 25 Oct 2026)
User guide linked from it: https://support.microsoft.com/topic/29dfd5fb-211a-4515-88a6-730b8074e489 (Microsoft Support, "Schedule your most used Copilot prompts")

Microsoft Copilot scheduled prompts let users automate Copilot interactions at specified times and frequencies across Microsoft Teams, Office.com chat, and Microsoft Outlook.

- Requires the Microsoft Copilot license and connected experiences ("Allow the use of connected experiences in Office").
- "Scheduled Prompts is available only in the Work IQ tab in Microsoft Copilot. Users won't see the option to create or manage scheduled prompts outside of the Work IQ tab."
- The scheduled prompts feature no longer relies on Power Automate flows.

From the Microsoft Support user guide:

1. Go to Copilot Chat and sign in with your Microsoft 365 account.
2. Hover over the prompt and select **Schedule this prompt**.
3. Select options for when the prompt will run, how many times it will run, and whether you'd like to get an email notification when the response is ready.
4. Select **Save**.

- You can create up to 10 different scheduled prompts.
- Responses appear in the **Chats** section (bolded, with an icon).
- Manage them under **... Settings and more** > **Scheduled prompts**: Run now, Edit Schedule, Turn off, Delete.
